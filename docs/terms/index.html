Group dungeon chat

Players in the same Group dungeon battle can chat with each other. There is no direct-message inbox or public chat. FiTama's server checks messages against a word filter before delivering them. The filter can miss harmful messages, so please use Report and Block.

  • Report sends the message and its details to FiTama for review. The reported player is not told who reported them.
  • Block hides that player's messages from you in every dungeon. It does not remove them from your party.

We review reports and act on them as quickly as we can. For urgent safety concerns, email support@fitama.app.
